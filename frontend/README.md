# Casino UI Study

A production-shaped crypto casino front end in **React 19 + Vite 7 + Tailwind
CSS v4**, backed by a small **Express 5** API. Built using bitcasino.io as a
layout and interaction reference.

```bash
npm install
npm run dev      # web :5173, api :4000
```

## What this is

A faithful reconstruction of the *layout, interaction patterns and design
system* of a modern casino lobby — sticky header, persistent category rail,
scroll-snap game rows, promo grid, themed light/dark palette.

It reproduces technique, not brand. The logo, favicon, game artwork, studio
logos and marketing copy are this project's own; none were taken from the
reference site, whose marks and licensed art belong to its operator and its
game studios. Design **tokens** come from the [Moon Design
System](https://github.com/coingaming/moon-design) (MIT), which the reference
site also uses.

Full breakdown: [docs/01 — Project overview](./docs/01-project-overview.md).

## This stack

React 19 · Vite 7 · Tailwind v4 · React Router 7 · Express 5 · Zod 4.

Plain JavaScript throughout — no TypeScript, no build-time type checking, and
no compile step on the API.

No component library, no CSS-in-JS, no icon package — icons are inline SVG,
carousels are native CSS scroll-snap. Production bundle is 321 KB (103 KB gzip).

Vite rather than Next.js because the goal is the UI layer; the component tree
is framework-portable if you later need SSR. Reasoning in
[docs/03 — Tech stack](./docs/03-tech-stack.md).

## Layout

```
apps/web/    React front end  (components/{ui,layout,sections}, pages, data, styles)
apps/api/    Express API      (routes, middleware, seed data)
scripts/     Asset + font generation
docs/        Project documentation
```

## Assets

Everything under `apps/web/public/` is generated by this repo or openly
licensed — 79 files, all accounted for in
[docs/07 — Assets and licensing](./docs/07-assets.md).

- `npm run fonts:fetch` — self-hosts DM Sans + Space Grotesk (SIL OFL)
- `npm run assets:gen` — generates game tiles, studio marks, hero and promo art, favicon,
  manifest, and PNG app icons

The asset script imports the catalog module directly — it is plain ESM — and
encodes PNGs with a hand-rolled encoder, so there is no native image
dependency anywhere in the toolchain. The drawings
themselves live in `scripts/art.mjs`.

## Status

UI shell, design system, routing, asset pipeline and read-only API are complete
and building. Accounts, wallets, payments and real game launches are out of
scope.

**This is not a gambling operator.** Running anything like it for real money
requires licensing, KYC/AML, geo-blocking, certified game integrations and
responsible-gaming controls — none of which are implemented here. See
[docs/09](./docs/09-roadmap.md).
